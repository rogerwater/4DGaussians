1. 问题描述 / PROBLEM DESCRIPTION
================================================================================

原始问题 (Chinese):
"我现在想要在更长的horizon的任务中试图使用此方法，但是我发现现有的方法对于
动作过大的情况会无法应对，查看中间结果可以发现，由于动作过大导致tapnet无法
不能够完成追踪"

翻译 (English):
"For longer-horizon tasks, the existing method cannot handle large motions. 
TAPNET fails to complete tracking when motions are too large."

核心问题 / Core Issue:
- TAPIR 追踪器在大动作场景下失败
- 导致 MPC 规划发散，无法完成长期任务

================================================================================
2. 解决方案 / SOLUTION
================================================================================

方案类型: 最小改动方案 (Minimal Modification Approach)
策略: 3层失败恢复机制 (3-Tier Failure Recovery)

【架构设计】

第1层: 追踪质量评估
- 使用 TAPIR 内置的不确定性指标 (occlusions, expected_dist)
- 计算置信度: confidence = (1 - sigmoid(occlusions)) * (1 - sigmoid(expected_dist))
- 阈值: 0.5 (来自 TAPIR 研究论文验证)

第2层: 光流恢复 (0.5 ≤ confidence < 0.7)
- 使用现有的 GMFlow + 一致性检查
- 调用 update_tracking_points_dynamic() 函数
- 优点: 快速 (~500ms)，适合中等退化

第3层: 完全重采样 (confidence < 0.5)
- 使用运动掩码 (motion mask) 重新采样点
- 从高运动区域重新选择追踪点
- 优点: 保证覆盖运动物体

6. 置信度阈值 / CONFIDENCE THRESHOLDS
================================================================================

研究验证的阈值 (Research-Validated):
--------------------------------------------------------------
confidence >= 0.7  → 正常运行 (Normal operation)
0.5 <= confidence < 0.7  → 尝试光流恢复 (Try flow recovery)
confidence < 0.5  → 必须重采样 (Must re-sample)

置信度计算:
--------------------------------------------------------------
confidence = (1 - sigmoid(occlusions)) * (1 - sigmoid(expected_dist))

其中:
  - occlusions: 遮挡概率 logit (越大越可能被遮挡)
  - expected_dist: 追踪误差大小 logit (越大误差越大)
  - 阈值 0.5 来自 TAPIR 论文 (256×256 下 8px, 512×512 下 16px)

8. 技术细节 / TECHNICAL DETAILS
================================================================================

TAPIR 不确定性指标:
--------------------------------------------------------------
expected_dist (预期距离):
  - 单位: pixels (logit 空间)
  - 含义: TAPIR 预测的追踪误差大小
  - 阈值: 8px @ 256×256 → 16px @ 512×512

occlusions (遮挡):
  - 范围: logit 空间 (-∞ 到 +∞)
  - 含义: 点被遮挡的概率
  - sigmoid(occlusions) ∈ [0, 1] 是实际概率

为什么这个方法有效:
--------------------------------------------------------------
1. 主动失败检测: 在完全失败前捕获退化
2. 分级响应: 先尝试廉价修复再用昂贵修复
3. 零新依赖: 使用现有 GMFlow 和 point_sampling 基础设施
4. 最小代码改动: <100 行新增代码，无架构变化
